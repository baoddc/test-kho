# Kế Hoạch Triển Khai: Đồng Bộ Google Sheet Sang Supabase & Autofill Form xg-nhap

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tạo bảng `xg_sap_mb51` trên Supabase, thêm nút "Đồng bộ Google Sheet" trên giao diện `xg-nhap.html`, và tích hợp chức năng tự động gợi ý/điền form khi nhập "Phiếu nhập" (kèm gộp dòng trùng và cộng dồn Quantity).

**Architecture:** 
- Database: Bảng `xg_sap_mb51` trên Supabase lưu trữ snapshot dữ liệu `mb51` từ Google Sheet với các index tối ưu tra cứu.
- Sync Service: Module JavaScript `assets/js/xg/xg-sync-service.js` đọc dữ liệu Google Sheet qua Google Visualization API (hoặc CSV) và nạp theo lô (batches) lên Supabase, hỗ trợ cập nhật tiến trình trên giao diện. Bổ sung script CLI `scripts/sync-ggsheet-mb51.py` dùng service account dự phòng.
- UI/UX Autofill: Tích hợp vào `assets/js/xg/xg-nhap.js` bộ lắng nghe ô Phiếu nhập (`col_3`), debounced query vào cache/bảng `xg_sap_mb51`, group by `(material, material_description, batch)`, cộng dồn `quantity` và hiển thị menu gợi ý nổi (floating dropdown). Khi chọn, tự động điền toàn bộ trường chung, điền tổng kg vào cuộn đầu tiên và sinh Cuộn ID.

**Tech Stack:** HTML5, Vanilla JavaScript (ES6+), Bootstrap 5, Supabase JS v2, Google Visualization API / Google Sheets API.

## Global Constraints
- Nguồn Google Sheet: `https://docs.google.com/spreadsheets/d/1BPY6k2bQuDu-RNpkRc3BhS57CuM1Ol__FYXvY8ezRjs/edit?gid=0#gid=0` (sheet `mb51`).
- Mặc định: `Mã chứng từ = 'MN'`, `Loại nhập = 'Nhà cung cấp'`.
- Mapping trường:
  - `Ngày nhập` <- `Posting Date` (định dạng `YYYY-MM-DD`)
  - `Phiếu nhập` <- `Material Document`
  - `Mã vật tư` <- `Material`
  - `Tên vật tư` <- `Material Description`
  - `Batch` <- `Batch`
  - `Mã công trình` <- `Project ID`
  - `Tên công trình` <- `Project name`
- Gộp trùng: Cùng số phiếu nhập, nếu trùng `Material`, `Material Description`, `Batch` thì gộp 1 dòng và cộng dồn `Quantity` (lấy số dương/giá trị tuyệt đối). Điền tổng kg vào cuộn đầu tiên.

### Task 1: Khởi Tạo Script SQL Cho Bảng `xg_sap_mb51` Trên Supabase

**Files:**
- Create: `scripts/setup_xg_sap_mb51.sql`

**Interfaces:**
- Produces: Table `public.xg_sap_mb51` với đầy đủ trường, indexes và quyền truy cập RLS.

- [ ] **Step 1: Tạo file `scripts/setup_xg_sap_mb51.sql`**
Viết mã DDL tạo bảng, đánh index trên `material_document`, `material`, kích hoạt RLS và thiết lập policy cho phép truy cập.

```sql
-- =============================================================================
-- SQL SETUP SCRIPT FOR TABLE: xg_sap_mb51
-- Run this script in Supabase SQL Editor to initialize SAP MB51 cache table
-- =============================================================================

CREATE TABLE IF NOT EXISTS public.xg_sap_mb51 (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    material_document TEXT NOT NULL,
    posting_date DATE,
    material TEXT,
    material_description TEXT,
    batch TEXT,
    quantity NUMERIC,
    project_id TEXT,
    project_name TEXT,
    storage_location TEXT,
    movement_type TEXT,
    movement_type_text TEXT,
    vendor_name TEXT,
    created_at TIMESTAMPTZ DEFAULT NOW(),
    updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- Index để tìm kiếm nhanh theo Phiếu nhập & Mã vật tư
CREATE INDEX IF NOT EXISTS idx_xg_sap_mb51_doc ON public.xg_sap_mb51 (material_document);
CREATE INDEX IF NOT EXISTS idx_xg_sap_mb51_mat ON public.xg_sap_mb51 (material);

-- Bật RLS
ALTER TABLE public.xg_sap_mb51 ENABLE ROW LEVEL SECURITY;

-- Cấp quyền đọc ghi cho anon và authenticated
DROP POLICY IF EXISTS "Allow all access to xg_sap_mb51" ON public.xg_sap_mb51;
CREATE POLICY "Allow all access to xg_sap_mb51" ON public.xg_sap_mb51
    FOR ALL USING (true) WITH CHECK (true);
```

### Task 4: Tích Hợp Autofill Và Xử Lý Gộp Quantity Trong `assets/js/xg/xg-nhap.js`

**Interfaces:**

- Produces: Tự động gắn sự kiện tìm kiếm khi gõ ô Phiếu nhập (`col_3`), hiển thị dropdown gợi ý, tự động điền form khi chọn item.

- [ ] **Step 1: Gắn sự kiện cho nút `#btnSyncGSheet` trong `xg-nhap.js`**

- [ ] **Step 2: Tích hợp chức năng Autocomplete vào `openAddDataModal()` trong `xg-nhap.js`**
- Tìm ô input `col_3` (Phiếu nhập).

- Khi giá trị có độ dài >= 3 ký tự, gọi `xgSyncService.fetchMb51Suggestions(val)`.
- Render dropdown danh sách các vật tư/batch của phiếu đó.
