# Admin Notification System (`bao.lt`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Thêm chức năng cho phép user admin `bao.lt` đăng, bật/tắt kích hoạt, và xóa thông báo (bảo trì, cập nhật, thông báo chung) tới tất cả người dùng ứng dụng Web và Desktop.

**Architecture:** Sử dụng bảng Supabase `system_announcements` lưu trữ thông báo. Mở rộng module `assets/js/update-checker.js` để tự động fetch thông báo active, hiển thị Toast Notification + Badge đỏ cho user thông thường, và hiển thị giao diện CRUD Admin trực tiếp trong Modal Chuông đối với tài khoản `bao.lt`.

**Tech Stack:** JavaScript (ES6+), Supabase JS Client, HTML5, Glassmorphic CSS.

## Global Constraints

- Chỉ hiển thị giao diện Quản lý thông báo khi `localStorage.getItem('currentUser') === 'bao.lt'`.
- Đồng bộ mã nguồn giữa `assets/js/update-checker.js` và `dist-app/assets/js/update-checker.js`.

### Task 1: Tạo SQL Script tạo bảng `system_announcements` trên Supabase

**Files:**
- Create: `scripts/create_system_announcements.sql`

**Interfaces:**
- Produces: Bảng Supabase `public.system_announcements` với RLS policy.

- [ ] **Step 1: Tạo file SQL `scripts/create_system_announcements.sql`**

```sql
-- Create system_announcements table
CREATE TABLE IF NOT EXISTS public.system_announcements (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    title TEXT NOT NULL,
    content TEXT NOT NULL,
    type TEXT DEFAULT 'info' CHECK (type IN ('maintenance', 'update', 'info', 'warning')),
    is_active BOOLEAN DEFAULT true,
    created_by TEXT DEFAULT 'bao.lt',
    created_at TIMESTAMPTZ DEFAULT now(),
    expires_at TIMESTAMPTZ NULL
);

-- Enable Row Level Security
ALTER TABLE public.system_announcements ENABLE ROW LEVEL SECURITY;

-- Allow read access for active announcements
CREATE POLICY "Allow public read active announcements" 
ON public.system_announcements FOR SELECT 
USING (true);

-- Allow full access for anon insert/update/delete
CREATE POLICY "Allow anon insert/update/delete announcements" 
ON public.system_announcements FOR ALL 
USING (true) WITH CHECK (true);
```

### Task 2: Cập nhật `assets/js/update-checker.js` với tính năng Thông báo & Admin CRUD

**Files:**
- Modify: `assets/js/update-checker.js`

**Interfaces:**
- Consumes: Supabase Client `window.supabase` từ `supabase-config.js`.
- Produces: Chức năng hiển thị Toast thông báo cho User + Giao diện Admin CRUD cho `bao.lt` trong Modal Chuông.

- [ ] **Step 1: Thêm hàm lấy dữ liệu thông báo từ Supabase & hiển thị Toast**

Trong `assets/js/update-checker.js`:
- Viết hàm `fetchSystemAnnouncements()` kết nối Supabase `system_announcements`.
- So sánh ID với `localStorage.getItem('read_announcements')`.
- Nếu có thông báo mới active (`is_active = true`), hiển thị Toast Popup góc dưới bên phải màn hình.

- [ ] **Step 2: Cập nhật Modal Chuông với Tab/Nút Quản lý Admin cho `bao.lt`**

- Kiểm tra `const currentUser = localStorage.getItem('currentUser'); const isAdmin = currentUser === 'bao.lt';`.
- Nếu `isAdmin = true`, hiển thị Nút **"⚙️ Quản lý thông báo"** trong Modal Chuông.
- Khi click, chuyển đổi giao diện Modal sang Form Tạo thông báo mới và Danh sách các thông báo hiện có kèm nút Toggle Active & Nút Delete.

- [ ] **Step 3: Viết các hàm tương tác Supabase (CRUD)**

- `createAnnouncement(title, type, content, expiryHours)`: Thực hiện `.insert(...)` vào `system_announcements`.
- `toggleAnnouncementActive(id, newStatus)`: Thực hiện `.update({ is_active: newStatus }).eq('id', id)`.
- `deleteAnnouncement(id)`: Thực hiện `.delete().eq('id', id)`.

