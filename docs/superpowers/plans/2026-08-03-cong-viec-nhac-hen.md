> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Triển khai tính năng Quản lý Công việc & Nhắc hẹn thời gian thực với trang điều hướng trên Sidebar, lưu trữ Supabase/LocalStorage, và thông báo âm thanh + popup cảnh báo.

### Task 1: Script Khởi Tạo CSDL Supabase (`scripts/setup_cong_viec_supabase.sql`)

**Files:**
- Create: `scripts/setup_cong_viec_supabase.sql`

**Interfaces:**
- Produces: Bảng `public.cong_viec` trên Supabase với RLS policy cho phép thao tác dữ liệu.

- [ ] **Step 1: Tạo file SQL khởi tạo bảng `cong_viec`**

Create `scripts/setup_cong_viec_supabase.sql`:
```sql
-- Create table cong_viec
CREATE TABLE IF NOT EXISTS public.cong_viec (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    tieu_de TEXT NOT NULL,
    ghi_chu TEXT,
    ngay_hen TIMESTAMPTZ NOT NULL,
    uu_tien TEXT NOT NULL DEFAULT 'trung_binh',
    trang_thai TEXT NOT NULL DEFAULT 'cho_xu_ly',
    da_nhac_hen BOOLEAN DEFAULT FALSE,
    user_created TEXT,
    created_at TIMESTAMPTZ DEFAULT NOW()
);

-- Enable RLS
ALTER TABLE public.cong_viec ENABLE ROW LEVEL SECURITY;

-- Drop policy if exists & recreate
DROP POLICY IF EXISTS "Allow all access to cong_viec" ON public.cong_viec;
CREATE POLICY "Allow all access to cong_viec" ON public.cong_viec
    FOR ALL USING (true) WITH CHECK (true);
```

- [ ] **Step 2: Kiểm tra cú pháp SQL và commit**

```bash

git commit -m "feat(sql): add setup script for cong_viec table"
```
