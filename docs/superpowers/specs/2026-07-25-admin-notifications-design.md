# System Notifications Feature for Admin (`bao.lt`) - Design Specification

## Overview
Cho phép tài khoản Quản trị viên (`bao.lt`) đăng, quản lý, bật/tắt và xóa các thông báo hệ thống (bảo trì, cập nhật phiên bản, thông báo chung) tới toàn bộ người dùng ứng dụng Web và Desktop (.exe). Thông báo được lưu trữ trên cơ sở dữ liệu Supabase, hiển thị sinh động qua Chuông thông báo (TopBar) và Toast Popup góc màn hình.

---

## 1. Database Schema (`system_announcements` on Supabase)

Bảng `system_announcements` được khởi tạo trên Supabase:

```sql
CREATE TABLE IF NOT EXISTS public.system_announcements (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    title TEXT NOT NULL,
    content TEXT NOT NULL,
    type TEXT DEFAULT 'info' CHECK (type IN ('maintenance', 'update', 'info', 'warning')),
    is_active BOOLEAN DEFAULT true,
    created_by TEXT DEFAULT 'bao.lt',
    created_at TIMESTAMPTZ DEFAULT now(),
    expires_at TIMESTAMPTZ NULL
);

-- Enable RLS
ALTER TABLE public.system_announcements ENABLE ROW LEVEL SECURITY;

-- Allow public read access for active announcements
CREATE POLICY "Allow public read active announcements" 
ON public.system_announcements FOR SELECT 
USING (true);

-- Allow full access (insert/update/delete) for all operations (using anon key with client checks)
CREATE POLICY "Allow anon insert/update/delete announcements" 
ON public.system_announcements FOR ALL 
USING (true) WITH CHECK (true);
```

## 2. User Interfaces & Workflows

### 2.1 General User Flow (Tất cả tài khoản)
1. **Truy vấn tự động**: Client nạp `assets/js/update-checker.js` (qua `sidebar.js`), tự động fetch các thông báo hoạt động từ Supabase:
   - Condition: `is_active = true` AND (`expires_at IS NULL` OR `expires_at > now()`)
2. **Hiệu ứng Chuông & Toast**:
   - Khi có thông báo chưa đọc (ID chưa nằm trong `localStorage.getItem('read_announcements')`):
     - Chuông trên TopBar (`#updateNotificationBell`) bật badge đỏ & hiệu ứng rung nhẹ.
     - Hiển thị Glassmorphic Toast góc dưới bên phải màn hình với phong cách màu sắc riêng theo từng loại thông báo (🛠️ Bảo trì - Cam/Đỏ, 🚀 Cập nhật - Xanh dương/Tím, 📢 Thông báo - Xanh lá).
3. **Xem danh sách trong Modal**:
   - Khi người dùng bấm vào Nút Chuông, Modal hiển thị danh sách các thông báo hệ thống đang hoạt động cùng mốc thời gian và thông tin phiên bản App.
   - Khi Modal mở ra, các ID thông báo được đánh dấu là "đã đọc" vào `localStorage`.

### 2.2 Admin Flow (`bao.lt`)
1. **Kiểm tra quyền hạn**:
   - Kiểm tra `localStorage.getItem('currentUser') === 'bao.lt'`.
2. **Giao diện Quản lý trong Modal Chuông**:
   - Trong Modal Chuông, hiển thị thêm Tab/Nút **"⚙️ Quản lý thông báo"** nổi bật.
   - Khi bấm vào nút này, chuyển đổi nội dung Modal sang giao diện Quản trị Admin:
     - **Form đăng thông báo**: 
       - Tiêu đề (Input text)
       - Loại thông báo (Select: 🛠️ Bảo trì, 🚀 Cập nhật, 📢 Thông báo chung, ⚠️ Cảnh báo)
       - Nội dung thông báo (Textarea)
       - Thời hạn tự động ẩn (Select: Không hết hạn, 24 giờ, 3 ngày, 7 ngày)
       - Nút **"🚀 Đăng thông báo ngay"**
     - **Danh sách quản lý thông báo hiện có**:
       - Danh sách thẻ thông báo gồm thông tin chi tiết.
       - Công tắc Toggle (Bật / Tắt trạng thái `is_active`).
       - Nút Xóa thông báo (Delete).

## 3. Technical Architecture & File Structure

1. **`assets/js/update-checker.js` & `dist-app/assets/js/update-checker.js`**:
   - Mở rộng module client để tích hợp truy vấn Supabase bảng `system_announcements`.
   - Bổ sung hàm render UI Admin CRUD dành cho `bao.lt`.
   - Đảm bảo tương thích hoàn toàn trên cả bản Web và bản Desktop Desktop Executable (`dist-app/`).

2. **`scripts/create_system_announcements.sql`**:
   - File SQL khởi tạo bảng dữ liệu trên Supabase.

## 4. Verification & Testing Plan

1. **Tạo bảng Supabase**: Chạy script SQL trên Supabase Dashboard.
2. **Kiểm thử Admin `bao.lt`**:
   - Đăng nhập tài khoản `bao.lt`.
   - Bấm Nút Chuông -> Kiểm tra xem có hiển thị tab "⚙️ Quản lý thông báo".
   - Đăng thử 1 thông báo Bảo trì và 1 thông báo Cập nhật.
   - Thử công tắc Bật/Tắt `is_active` và nút Xóa.
3. **Kiểm thử User thông thường**:
   - Đăng nhập tài khoản khác (hoặc chưa đăng nhập).
   - Kiểm tra Toast popup xuất hiện ở góc dưới màn hình.
   - Kiểm tra chuông rung + badge đỏ.
   - Mở modal xem danh sách thông báo và kiểm tra `localStorage` đã đánh dấu đã đọc.
